# 第三方内容署名

题目名称、分组、题面与公开示例来自 [力扣 LeetCode 热题 100](https://leetcode.cn/studyplan/top-100-liked/) 及各题原题页面。题面已转换为适合本站展示的纯文本 Markdown；各题 `description.md` 保留原题链接。

参考题解与代码来自 [Doocs LeetCode](https://github.com/doocs/leetcode) 项目贡献者，按 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 许可署名共享。每题的 `sources/doocs.json` 记录对应原始页面。本站从各题 README 中选取可用语言的代码块，补充了部分 Python 标准库导入，并将题解文本转换为本站的数据格式；这些改编的参考题解继续按 CC BY-SA 4.0 提供。

早先已独立编写的“两数之和”及首批十题的原有实现保持不变；只有本次新增的参考语言代码使用上述来源。
